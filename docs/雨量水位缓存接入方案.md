# 雨量与水位缓存接入方案

## 一、总体架构

雨量、水位数据不建议由手机端或问答系统实时直连外网接口。系统采用中间库缓存方式：

外网采集服务 -> 数据清洗 -> 中间数据库 -> 高切坡系统 -> 自然语言查询模块

现场演示或巡查时，即使外网服务暂时不可用，系统仍可基于最近一次缓存数据回答。

## 二、已选数据源

### 1. 雨量数据

当前 Demo 优先选用 Open-Meteo，原因是不需要 API Key，可直接按经纬度查询小时级降水、预报和历史天气，适合快速验证“外网采集服务 -> 中间库 -> 问答系统”的完整链路。

Open-Meteo 属于模型或再分析数据，不是中国本地雨量站实测数据，正式业务中应作为辅助参考。

默认配置：

- `WEATHER_PROVIDER=open_meteo`
- `OPEN_METEO_BASE_URL=https://api.open-meteo.com`

如后续需要商业天气能力，可切换和风天气 API，支持按经纬度查询实时天气、逐小时预报、分钟级降水和灾害预警。

- `WEATHER_PROVIDER=qweather`
- `QWEATHER_API_KEY=你的和风天气Key`
- `QWEATHER_BASE_URL=https://devapi.qweather.com`

备选接入心知天气：

- `WEATHER_PROVIDER=seniverse`
- `SENIVERSE_API_KEY=你的心知天气Key`
- `SENIVERSE_BASE_URL=https://api.seniverse.com`

如果后续拿到气象部门、自有雨量站或区县雨量站接口，可使用通用模式：

- `WEATHER_PROVIDER=generic`
- `RAIN_API_URL=授权接口地址`
- `RAIN_API_KEY=授权密钥`

正式业务优先级建议为：自有雨量站/区县雨量站 > 气象部门授权接口 > 商业天气 API > Open-Meteo 模型数据。

### 2. 水位数据

当前已接入长江水文网公开实时水情表，并写入中间库。采集字段包括站名、河流、观测时间、水位、流量等。

配置方式：

- `WATER_PROVIDER=cjh_public`
- `CJH_WATER_URL=https://www.cjh.com.cn/sssqcwww.html`

目前对三峡库区高切坡，在没有建立专属水文站映射时，系统优先使用宜昌站作为水位参考；如果 `ai_slope_hydro_station_map` 中配置了某个高切坡对应的水文站，则优先使用该专属映射。

正式系统建议后续替换为：

- 水文部门授权接口
- 前置库交换
- 定时文件交换
- 三峡平台数据共享接口

## 三、中间库表

建表脚本：

`backend/scripts/setup_hydro_meteor_cache.py`

已创建三张表：

- `ai_weather_rainfall_cache`：雨量缓存表
- `ai_hydro_water_level_cache`：水位缓存表
- `ai_slope_hydro_station_map`：高切坡与雨量站、水文站对应关系表
- `ai_hydro_meteor_daily_cache`：日尺度雨量、水位缓存表，用于与月报、位移和异常记录交叉分析

核心字段包括：

- 高切坡编号、区县、乡镇
- 雨量站或水文站编号、名称、经纬度
- 观测时间
- 1小时、3小时、24小时、72小时累计雨量
- 当前水位、24小时水位变化、72小时水位变化、流量
- 日雨量、日均水位、日均流量
- 数据来源、原始报文、采集时间

## 四、采集脚本

采集脚本：

`backend/scripts/collect_hydro_meteor_cache.py`

示例：

```powershell
$env:WEATHER_PROVIDER='open_meteo'
$env:WATER_PROVIDER='cjh_public'
$env:HYDRO_METEOR_TARGETS='ZG0098,ZG0095'
python backend/scripts/collect_hydro_meteor_cache.py
```

如暂时只想采集水位：

```powershell
$env:WEATHER_PROVIDER='none'
$env:WATER_PROVIDER='cjh_public'
python backend/scripts/collect_hydro_meteor_cache.py
```

建议部署在可访问外网或政务网数据接口的服务器上，通过 Windows 计划任务、Linux crontab 或调度平台定时执行。

推荐频率：

- 汛期：5-15 分钟一次
- 非汛期：30-60 分钟一次
- 现场演示前：手动执行一次，确保缓存为最新

## 五、历史日尺度回填

已提供 2025 年以来日尺度雨量、水位缓存回填脚本：

`backend/scripts/backfill_daily_hydro_meteor_cache.py`

Demo 阶段，日雨量使用 Open-Meteo Historical Weather API，不需要 API Key。水位历史方面，当前公开实时水情页不提供完整历史接口，因此脚本只会把已经采集到的水位缓存按日聚合；如需完整 2025 年以来日水位序列，应接入水文部门授权接口、前置库或定时交换文件。

示例：回填指定高切坡 2025-01-01 至当前日期的日雨量：

```powershell
$env:HYDRO_METEOR_TARGETS='ZG0098,ZG0095'
$env:HYDRO_DAILY_START_DATE='2025-01-01'
$env:HYDRO_DAILY_END_DATE='2026-06-17'
python backend/scripts/backfill_daily_hydro_meteor_cache.py
```

如需批量回填更多高切坡：

```powershell
$env:HYDRO_DAILY_TARGET_LIMIT='600'
$env:HYDRO_DAILY_START_DATE='2025-01-01'
$env:HYDRO_DAILY_END_DATE='2026-06-17'
python backend/scripts/backfill_daily_hydro_meteor_cache.py
```

当前已完成测试回填：

- `ZG0098`：2025-01-01 至 2026-06-17，共 533 条日雨量记录
- `ZG0095`：2025-01-01 至 2026-06-17，共 533 条日雨量记录

## 六、自然语言查询

系统已支持以下问法：

- ZG0098最近降雨和水位变化情况
- 这处高切坡最近24小时降雨量是多少？
- 这处高切坡最近72小时累计降雨是多少？
- 最近库水位变化期间，这处高切坡监测数据有没有异常？
- 请综合降雨、库水位和监测数据，判断这处高切坡近期风险。

如果上一轮问题中已经出现高切坡编号，例如 `ZG0098`，后续可直接追问“这处高切坡最近24小时降雨量是多少”。

## 七、回答口径

示例：

该高切坡最近24小时累计降雨38.6毫米，最近72小时累计降雨71.2毫米；三峡库区参考水位较昨日上涨0.32米。结合近期专业监测和群测群防记录，暂未发现明显雨后变形响应。建议继续关注裂缝、挡墙开裂、坡脚渗水和排水不畅部位。

注意：

- 不使用“绝对安全”“没有风险”等绝对化表述。
- 外部环境数据只作为辅助研判依据。
- 缓存数据缺失时，应提示“暂未取得有效缓存数据”，并建议结合现场巡查和专业监测判断。

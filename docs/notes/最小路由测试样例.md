# 最小路由测试样例

用于人工验证高切坡智能查询 Agent 当前 5 类问题路由是否符合预期。

## 一、测试目标

验证以下 5 类路由是否能被正确识别：

1. `db_query`
2. `result_analysis`
3. `template_query`
4. `clarify`
5. `out_of_scope`

---

## 二、`db_query` 测试样例

这类问题应进入普通数据库查询主链路。

### 样例 1

```text
最近有哪些高切坡存在异常状态
```

预期：

- `query_type = db_query`
- 进入查库流程

### 样例 2

```text
统计各区县高切坡数量
```

预期：

- `query_type = db_query`
- 返回统计结果

### 样例 3

```text
查询最近30天的预警专报记录
```

预期：

- `query_type = db_query`
- 返回预警专报相关结果

### 样例 4

```text
查询渝北区最近的巡查异常记录
```

预期：

- `query_type = db_query`
- 进入巡查/异常相关查询

---

## 三、`result_analysis` 测试样例

这类问题应先查表，再生成分析型总结。

### 样例 1

```text
帮我分析最近异常高切坡的分布情况
```

预期：

- `query_type = result_analysis`
- 总结偏“分布、特点、重点现象”

### 样例 2

```text
总结一下近一个月哪些区县高切坡异常比较多
```

预期：

- `query_type = result_analysis`
- 结果总结偏“对比和归纳”

### 样例 3

```text
对比一下各区县高切坡异常数量
```

预期：

- `query_type = result_analysis`
- 总结偏“对比关系”

### 样例 4

```text
研判最近巡查异常的主要特征
```

预期：

- `query_type = result_analysis`
- 不只是列明细，还应提炼规律

---

## 四、`template_query` 测试样例

这类问题应命中稳定模板，不让 LLM 自由选口径。

### 样例 1

```text
我想知道哪些高切坡处于异常状态，并告诉我属于哪一种异常类型
```

预期：

- `query_type = template_query`
- 命中异常类型模板
- 表格中应出现 `abnormal_type`

### 样例 2

```text
哪些高切坡有异常，并告诉我具体是什么异常
```

预期：

- `query_type = template_query`
- 不应只返回 overallSituation

### 样例 3

```text
请列出异常高切坡，并说明分别属于哪类异常
```

预期：

- `query_type = template_query`
- 异常类型来自明确异常字段

---

## 五、`clarify` 测试样例

这类问题应提示用户补充条件，不直接查库。

### 样例 1

```text
查一下
```

预期：

- `query_type = clarify`
- 提示问题过短

### 样例 2

```text
看看异常
```

预期：

- `query_type = clarify`
- 提示补充地区、时间或异常类型

### 样例 3

```text
帮我分析一下
```

预期：

- `query_type = clarify`
- 不应直接查库

### 样例 4

```text
查一下最近情况
```

预期：

- `query_type = clarify`
- 提示缺少高切坡业务对象或查询范围

---

## 六、`out_of_scope` 测试样例

这类问题应直接拒答，不进入查询流程。

### 样例 1

```text
查询系统账号和密码
```

预期：

- `query_type = out_of_scope`
- 理由偏账号/权限敏感信息

### 样例 2

```text
帮我写一段 Python 代码
```

预期：

- `query_type = out_of_scope`
- 理由偏非高切坡业务

### 样例 3

```text
今天天气怎么样
```

预期：

- `query_type = out_of_scope`
- 理由偏非业务问题

### 样例 4

```text
查看权限配置和角色信息
```

预期：

- `query_type = out_of_scope`
- 理由偏系统管理信息

## 八、最小回归集

如果每次只想跑最小回归，优先测这 5 条：

```text
最近有哪些高切坡存在异常状态
帮我分析最近异常高切坡的分布情况
我想知道哪些高切坡处于异常状态，并告诉我属于哪一种异常类型
查一下
查询系统账号和密码
```

这 5 条分别对应 5 种分类，是当前最小可用的路由回归样例集。

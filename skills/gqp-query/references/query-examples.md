# Minimal Query Examples

Use these examples for manual route validation and regression checks.

## `db_query`

- 最近有哪些高切坡存在异常状态
- 统计各区县高切坡数量
- 查询最近30天的预警专报记录
- 查询渝北区最近的巡查异常记录

## `result_analysis`

- 帮我分析最近异常高切坡的分布情况
- 总结一下近一个月哪些区县高切坡异常比较多
- 对比一下各区县高切坡异常数量
- 研判最近巡查异常的主要特征

## `template_query`

- 我想知道哪些高切坡处于异常状态，并告诉我属于哪一种异常类型
- 哪些高切坡有异常，并告诉我具体是什么异常
- 请列出异常高切坡，并说明分别属于哪类异常

## `clarify`

- 查一下
- 看看异常
- 帮我分析一下
- 查一下最近情况

## `out_of_scope`

- 查询系统账号和密码
- 帮我写一段 Python 代码
- 今天天气怎么样
- 查看权限配置和角色信息

## Smallest Regression Set

```text
最近有哪些高切坡存在异常状态
帮我分析最近异常高切坡的分布情况
我想知道哪些高切坡处于异常状态，并告诉我属于哪一种异常类型
查一下
查询系统账号和密码
```
